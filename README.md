# Employee Management System

A Python-based Employee Management System developed for learning Python programming, file handling, and data management.

## Features

* Add Employee
* View Employees
* Search Employee by ID
* Update Employee Details
* Delete Employee
* Count Employees
* Calculate Total Salary
* Calculate Average Salary
* Find Highest Salary Employee
* Find Lowest Salary Employee
* Search by Department
* Department-wise Salary Calculation
* Save Data to File
* Load Data from File
* Export Data to CSV

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* File Handling
* CSV Handling
